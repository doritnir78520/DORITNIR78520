# DORITNIR78520 — Modern Home Decor & Furniture

**Design Your Space. Elevate Your Living.**

A responsive, multi-page static concept storefront designed for GitHub Pages.

## Brand
- Sage green: `#788B75`
- Natural beige: `#D9C7AB`
- Warm cream: `#FAF7F0`
- Language: English

## Pages
- `index.html` — Home
- `shop.html` — Searchable/filterable product catalog
- `collections.html` — Collection categories
- `inspiration.html` — Interior inspiration gallery
- `about.html` — Brand story
- `contact.html` — Demo contact form
- `faq.html` — FAQs
- `privacy.html` — Privacy information
- `terms.html` — Website terms

## Features
- Responsive design with mobile menu
- 12 illustrative products, USD prices
- Working search and category filters
- Interactive demo shopping bag with quantity controls and localStorage
- Demo wishlist with localStorage
- Accessible form fields and navigation
- No framework or build tools required

## Launch on GitHub Pages
1. Extract this ZIP.
2. Upload **the contents** of this folder (not the folder itself) to the root of a public GitHub repository.
3. Go to **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Open the URL GitHub provides after deployment.

## IMPORTANT: DEMONSTRATION ONLY
All product names, prices, descriptions and inventory are illustrative. The shopping bag and wishlist are browser-only. No payments, checkout, customer accounts, or live ordering. Forms are front-end only and do not submit data. Do not advertise sample products as available without verification.
